# Final-Project-Structure-Smart-running-glasses-wiper
Simulation of a weather-triggered wiper system for people who use glasses as they run.
## Project Goal
Java based software simulation of a weather-triggered wiper system for runners who wear glasses in rainy or humid conditions. 
## MVP Scope
Virtual sensor simulation showing live humidity percentages
if/else logic to determine wiper frequency
## Future Schedule
Core simulation loop
Integration with a weather API in real time
Expanded UI and hardware mapping
## Tech Stack
Language: Java
Tools: Java libraries
